# Как проверить, что на Vercel задеплоен правильный код из Git

## Способ 1: Проверка через веб-интерфейс Vercel

1. Зайдите на https://vercel.com
2. Откройте ваш проект
3. Перейдите в раздел **Deployments**
4. Найдите последний деплой (самый верхний)
5. Нажмите на него, чтобы открыть детали

### Что проверить:

1. **Commit SHA** - это хеш коммита из Git
   - Нажмите на SHA (например, `a1b2c3d`)
   - Откроется страница коммита в GitHub/GitLab

2. **Commit Message** - сообщение коммита
   - Должно совпадать с вашим последним коммитом

3. **Status** - должен быть `Ready` (зеленый)

4. **Source** - должен показывать ветку (обычно `main` или `master`)

## Способ 2: Сравнение через Git

### Шаг 1: Узнайте SHA последнего коммита в Git

```bash
git log --oneline -1
```

Или полный SHA:
```bash
git rev-parse HEAD
```

### Шаг 2: Проверьте SHA на Vercel

1. Зайдите в **Deployments** на Vercel
2. Найдите SHA последнего деплоя
3. Сравните с SHA из Git

### Шаг 3: Если SHA не совпадает

Если SHA на Vercel отличается от вашего последнего коммита:

1. **Проверьте, запушили ли вы изменения:**
   ```bash
   git status
   ```
   
   Если есть незакоммиченные изменения или не запушенные коммиты:
   ```bash
   git add .
   git commit -m "Your message"
   git push
   ```

2. **Проверьте, какая ветка подключена к Vercel:**
   - В настройках проекта Vercel → **Settings** → **Git**
   - Убедитесь, что выбрана правильная ветка (обычно `main`)

## Способ 3: Проверка через Vercel CLI

Если у вас установлен Vercel CLI:

```bash
vercel ls
```

Покажет список деплоев с их SHA коммитов.

## Способ 4: Проверка файлов в деплое

### На Vercel:

1. Откройте деплой на Vercel
2. Перейдите в **Source** или **Build Logs**
3. Найдите файл `src/lib/firebase.ts` в логах сборки

### В Git:

```bash
git show HEAD:src/lib/firebase.ts
```

Сравните содержимое - должно совпадать.

## Способ 5: Проверка через консоль браузера

1. Откройте задеплоенный сайт
2. Откройте консоль браузера (F12)
3. Найдите сообщения о Firebase конфигурации

Если видите:
- `❌ Firebase конфигурация неполная` - значит код с проверкой задеплоен
- Нет таких сообщений - возможно, старая версия кода

## Быстрая проверка

### Команда для проверки всех изменений:

```bash
# Показать последний коммит
git log --oneline -1

# Показать, есть ли незакоммиченные изменения
git status

# Показать, есть ли не запушенные коммиты
git log origin/main..HEAD 2>/dev/null || git log origin/master..HEAD 2>/dev/null || echo "Все коммиты запушены"
```

## Что делать, если код не совпадает:

1. **Убедитесь, что все изменения закоммичены:**
   ```bash
   git add .
   git commit -m "Update Firebase config"
   ```

2. **Запушьте в Git:**
   ```bash
   git push
   ```

3. **Проверьте, что Vercel начал новый деплой:**
   - Зайдите в **Deployments** на Vercel
   - Должен появиться новый деплой со статусом "Building"

4. **Дождитесь завершения деплоя:**
   - Статус должен стать "Ready" (зеленый)

5. **Проверьте SHA нового деплоя:**
   - Должен совпадать с вашим последним коммитом
