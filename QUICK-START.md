# Быстрый старт для деплоя

## ⚠️ Проблема с билдом

Сейчас проект не собирается из-за динамических маршрутов. Есть два варианта решения:

### Вариант 1: Использовать Vercel (рекомендуется для Next.js)

Vercel - это платформа от создателей Next.js, которая идеально подходит для деплоя Next.js приложений:

1. Зарегистрируйтесь на https://vercel.com
2. Подключите GitHub репозиторий
3. Vercel автоматически определит Next.js и задеплоит проект
4. PWA будет работать автоматически

### Вариант 2: Исправить статический экспорт

Если нужно использовать Firebase Hosting, нужно исправить проблему с динамическими маршрутами. 

Временное решение - убрать `output: "export"` из `next.config.ts` и использовать Firebase Functions для SSR, но это сложнее.

## Создание иконок

Перед деплоем создайте иконки:
- `public/apple-touch-icon.png` (180x180)
- `public/icon-192.png` (192x192)  
- `public/icon-512.png` (512x512)

Используйте: https://realfavicongenerator.net/

## Установка на iPhone

После деплоя:
1. Откройте сайт в Safari
2. Нажмите "Поделиться" → "На экран «Домой»"
3. Нажмите "Добавить"
